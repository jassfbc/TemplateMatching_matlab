# TemplateMatching_matlab
 This project implements a spectrogram-based template matching algorithm in MATLAB to detect specific words within spoken audio clips. Using samples from the Google Speech Commands Dataset, the system extracts spectrograms from both target words and full audio sequences, then applies normalized cross-correlation to identify the most likely position of the target word within the audio.  Key Features:  Spectrogram extraction and visualization  Template matching using cross-correlation  Word detection with position estimation  Based on real-world speech data (Google Speech Commands Dataset)
